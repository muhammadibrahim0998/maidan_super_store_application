# SuperPerFume-Shop-Application

PerFume Shop Center - Complete Perfume Inventory, POS, Multi-Branch & Storefront Management Application.

## Overview
- **Backend:** Node.js, Express, MongoDB (Mongoose)
- **Frontend:** React, Vite, Tailwind CSS, Lucide Icons
- **Features:**
  - Executive Business Dashboard (Real-time financial analytics, revenue, stock worth)
  - Products & Inventory Management (Boxes, Packs, Bottles / Pieces)
  - Point of Sale (POS) & Walk-in billing
  - Multi-Branch & Super Admin Management
  - Customer Storefront & Online Ordering

## Setup & Run
### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
